源码版本日期：2026-10-24；公开同步整理：2026-10-26。
本次将 0.2.2 运行代码和最新使用文档同步到 `linker-bot/primitive`，供独立示教、
ROS 驱动接入和应用集成使用。包版本保持 `0.2.2`；本次 PR 不创建 Git 标签或
GitHub Release，安装时请记录所用公开提交的完整 SHA。

下载、独立 Mock 和 ROS 安装步骤见[安装与启动指南](../getting-started.md)，
网页操作见[用户手册](../teach-panel-user-guide.md)。

## 功能与兼容

- 保留原有 40 项注册原语，包括 13 项视觉感知原语，以及各手型的支持范围。
  缺少反馈、感知目标、FK 或门控条件时显示原因，不从目录中删除原语。
- 保留自定义姿态、多关键帧、载入编辑、排序、重命名、单帧和整段回放，
  以及姿态包导入导出、冲突策略、校验和、出厂预设。
- 默认页面恢复原手掌滑条、关键帧树和姿态库；同页提供内置原语、速度与左右手选择。
  `/legacy` 保留兼容入口，`/workbench` 提供按住推进与菜单等扩展操作。
- 新增 0.25–3.0 倍速、有限动作按住推进/松开暂停/再次按住续播，以及自定义动作
  进度控制。持续感知与力控闭环不支持任意进度跳转；速度倍率不改变接触保护时间。
- 保留原有 ROS 字符串、Float32 进度、旧面板 WebSocket 和姿态 CLI 入口。
  新控制路径绑定执行身份，停止或失权后拒绝迟到的旧控制请求。
- 修复默认手侧与姿态库侧别一致性、L25 通道转换、失焦释放、预览起点重锚、
  轨迹完成与反馈到位判定、力矩反馈新鲜度，以及旧面板完成后返回示教的兼容行为。
- 安装包携带仓库原有 O6 右手 URDF 与 meshes；ROS 面板通过原语节点控制，
  不与节点同时直接发送手目标。Mock 不创建 ROS 节点或硬件驱动。

逐项功能对应及回归测试见 [兼容清单](../workbench-feature-compatibility.md)。

## 安装与数据升级

完整命令见 [工作台使用说明](../workbench.md)。独立 Mock 安装支持普通 Python
环境；ROS 2 Jazzy 使用系统 Python 3.12 创建的独立 venv，提供 Pydantic 2，
并保持 apt NumPy/SciPy 和 ROS 扩展。不要用 Noble 的 apt Pydantic 1 代替此要求。

所有使用同一姿态库的进程都需显式设置 `HAND_GESTURE_POSE_DIR`，按手型与左右侧
分别存储。新版本不自动读取旧 HOME 目录，也不自动改写现有姿态；可通过姿态包迁移。
升级时保留原姿态目录与旧安装，在新目录安装并明确选择对应环境。

本次仅支持原有 ROS 驱动接入与 Mock，没有新增 SDK/CAN 直连模式。
原仓库代码保留 MIT 许可证；提取的公共工作台代码为 Apache-2.0，详见根目录
`NOTICE` 和随安装包交付的许可证文件。

## 已知限制

- 原手掌布局在 390px 手机视口仍有横向溢出，本轮界面以桌面验收为准。
- 仓库仅自带 O6 右手模型；O6 左手及其他未提供模型仍需真实外部 URDF，
  不使用右手模型猜测或镜像替代。O30 模型缺失的对应测试未执行。
- 感知/力控闭环没有本次现场验收结果；实际运行需要有效目标、反馈及对应门控条件。
- 停止 ACK 表示执行器停止处理动作，不代表已经测得电机物理停稳。
